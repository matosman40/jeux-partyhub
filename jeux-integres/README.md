# Jeux intégrés à PartyHub

Ce dossier décrit les 29 jeux écrits dans le code de PartyHub (registre `packages/games/src/index.ts`). Vingt-huit fiches ont été générées depuis la version 0.14.0, branche `main`, commit 33cf929 ; celle de l’Essai des appareils est rédigée d’après la version 0.17.5. Le numéro de version d’une fiche suit celui du paquet dans `jeux/` quand le jeu en a un. Le code de ces jeux est dans PartyHub, et la plupart ont aussi un paquet de jeu de code dans `jeux/`.

Chaque fiche donne le but, le déroulement, les conseils, le nombre de joueurs, la version du jeu, le fichier source dans PartyHub et les mentions de ce jeu dans le journal de PartyHub.

Les fiches sont du texte seul : aucun code de l’application n’est copié et aucun visuel n’est dupliqué. Elles ne se mettent pas à jour toutes seules. Après un changement de règles dans PartyHub, la fiche concernée doit être refaite à la main.

Karaoké, tennis party, Tribunal de l’absurde, téléphone arabe, plateau fête et Imposteur parmi nous sont des jeux de code publiés dans `jeux/`. Ils ne sont pas dans le registre de PartyHub et n’ont pas de fiche ici.
