# Sons CC0 (Openverse)

Huit sons courts, téléchargés depuis Openverse (filtre licence CC0). La source et l'auteur de chaque son sont dans
[SOURCES.json](SOURCES.json). Ces sons ne sont pas encore dans un paquet : ils servent de banque, à affecter dans
l'administration de PartyHub (médiathèque, emplacements de bruitages).

| Fichier | Usage prévu |
|---|---|
| `bonne-reponse.mp3` | bonne réponse (quiz) |
| `erreur.mp3` | mauvaise réponse |
| `compte-a-rebours.mp3` | décompte |
| `votre-tour.mp3` | notification de tour |
| `victoire.mp3` | victoire |
| `explosion.mp3` | explosion |
| `clic.mp3` | clic |
| `carte.mp3` | carte posée |

Licence : CC0 1.0 (domaine public), d'après la fiche de chaque son sur Freesound. Une écoute en jeu reste nécessaire avant
livraison.
